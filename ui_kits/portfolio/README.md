# UI kit — сборник кейсов

Четыре экрана одного продукта. Все собраны из компонентов системы; в кит не добавлено
ни одного нового визуального решения.

| Файл | Экран |
| --- | --- |
| `index.html` | Главная, десктоп 1440 — первый экран, лента, футер (кликабельно) |
| `case-desktop.html` | Страница кейса, десктоп 1440 |
| `home-mobile.html` | Главная, мобильный 390 |
| `case-mobile.html` | Страница кейса, мобильный 390 |

- `data.js` — дословные тексты сборника (`window.PF`).
- `Screens.jsx` — `HomeScreen`, `CaseScreen`, `App` (переход главная ↔ кейс, фильтры).

Мобильная раскладка приходит из container query на `.pf`, а не из media query,
поэтому экран 390 корректен внутри любого фрейма.
