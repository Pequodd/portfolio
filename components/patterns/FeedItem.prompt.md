Единица ленты. Ритм: во всю ширину → два в ряд 50/50 → во всю ширину. Больше двух в ряд не ставить.

```jsx
<FeedItem number="01" name="Строительная компания" stack="Tilda · многостраничный · с нуля · 2024"
  title="Каталог объектов, который команда пополняет сама" size="1360×850" />
```

Для пары оборачивать два элемента в `<div className="pf-feed__pair">`.
